# Security Policy

## Supported Versions

The following versions of NeuroSim are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in NeuroSim, please report it immediately to our security team. **Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, please send an email to [security@neuro-space.io](mailto:security@neuro-space.io).

### What to Include

When reporting a vulnerability, please include as much information as possible to help us reproduce and address the issue, including:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the vulnerability.
- Any relevant screenshots or screen recordings.
- Your preferred method of contact for follow-up questions.

### Our Commitment

We take all security reports seriously and will respond to your report as quickly as possible. We will work with you to understand the vulnerability and develop a fix. We will also keep you informed of our progress and provide a timeline for when the fix will be released.

Thank you for helping us keep NeuroSim secure!
