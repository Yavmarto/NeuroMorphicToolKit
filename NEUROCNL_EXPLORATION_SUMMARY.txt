KEY FINDINGS
================================================================================

ARCHITECTURE:
- neurocnl is a 5-stage pipeline: Parse → Validate → Generate → Simulate → Assert
- Pure regex-based parser (NO LLM required) with 13 concept patterns
- Layer 1: Physical invariants (18 checks against neuron params)
- Layer 2: Cross-sentence consistency (dangling connections, contradictions)
- Layer 3: Auto-generated pytest assertions for behavioral validation

THE 13 CONCEPTS (All Patterns Documented):
 1. threshold_firing          - Fire when membrane potential exceeds X
 2. refractory_period         - Blocked for X seconds after spike
 3. membrane_potential_decay  - Voltage decay with time constant τ
 4. synaptic_weight           - Connection strength X (required core)
 5. axonal_delay              - Transmission delay X ms/seconds
 6. stdp_learning             - Spike-timing-dependent plasticity rules
 7. inhibitory_connection     - Negative-weight suppressive connections
 8. population_coding         - N neurons representing D dimensions
 9. network_topology          - Multi-population architectures
10. lateral_inhibition        - Competitive self-organization
11. homeostatic_plasticity    - Maintain target firing rate
12. neuromodulation           - Modulatory signals (dopamine, etc.)
13. population_coding_range   - Stimulus feature ranges (angles, frequencies)

CRITICAL FUNCTIONS:

run_pipeline(spec_text, backend="nengo", ...) → PipelineResult
  - Single entry point for entire 5-stage pipeline
  - Returns PipelineResult with parsed, validated, network, simulation, assertions
  - Automatically extracts params, validates against invariants, generates SNN, simulates
  - Returns overall_pass=True only if ALL stages succeed

parse(sentence: str) → ParsedSentence
  - Regex-based parser for 13 concepts
  - No NLP/LLM, pure pattern matching
  - Raises ParseError if no pattern matches
  - Returns: {concept, subject, action, verb, negated, condition, raw}

validate(parsed_specs, neuron_params, backend="nengo") → dict
  - Layer 1: Checks 18 biological invariants (or 21 if Loihi)
  - Validates LIF model constraints (threshold > rest, tau > 0, etc.)
  - Returns: {passed: [str], failed: [{name, reason}], overall: bool}

generate(parsed_specs, neuron_params) → nengo.Network
  - Creates Nengo SNN with:
    * Dynamic populations from specs
    * LIF neurons with tau_rc, tau_ref, threshold
    * Synaptic connections with weights
    * Input node (stimulus) + output probe
    * Learning rule nodes (STDP/BCM/Oja) if specified
  - Returns net with backward-compat attributes: net.sensory, net.motor

export(net, format: str) → str
  - Formats: 'c_header', 'neuroml', 'loihi', 'lava', 'spinnaker'
  - C header exports LIF params + weight arrays + update loop for microcontrollers
  - NeuroML for interoperability, Loihi/Lava/SpiNNaker for neuromorphic hardware

EXAMPLE FLOW:

1. Write CNL Spec:
   "The sensory neuron MUST fire ONLY IF membrane potential exceeds 0.8"
   "The sensory neuron MUST NOT fire DURING the refractory period of 0.002 seconds"
   "The sensory neuron membrane potential MUST decay WITH time constant of 0.01 seconds"
   "The connection from sensory neuron to motor neuron MUST have WITH synaptic weight of 1.5"

2. Parse:
   parsed = [parse(line) for line in spec_text.split('\n')]
   → 4 ParsedSentence dicts

3. Validate:
   report = validate(parsed, {"threshold": 0.8, "tau": 0.01, ...})
   → {"passed": [18 invariant names], "failed": [], "overall": True}

4. Generate:
   net = generate(parsed, params)
   → nengo.Network with sensory/motor ensembles, 1.5-weight connection

5. Simulate:
   with nengo.Simulator(net) as sim:
       sim.run(1.0)  # 1 second
   → motor outputs recorded in net.motor_probe

6. Assert:
   generate_assertions(parsed) → pytest_code
   pytest test_*.py → assertions passed/failed

ALL 6 STEPS: run_pipeline(spec_text) → PipelineResult with everything

LAYER 1 INVARIANTS (18 Total)
================================================================================

Core LIF Model (6):
  1. threshold_above_resting      - threshold > resting_potential
  2. refractory_period_positive   - refractory_period > 0
  3. time_constant_positive       - tau > 0
  4. reset_at_or_below_threshold  - reset_potential ≤ threshold
  5. membrane_potential_decays_toward_rest - dv/dt = (rest - v)/tau
  6. axonal_delay_in_range        - 0 ≤ delay ≤ max_delay

Learning/Plasticity (5):
  7. stdp_window_positive         - 0 < window ≤ 100ms
  8. stdp_weight_bounds_valid     - w_min < w_max
  9. inhibitory_weight_negative   - weight ≤ 0
 10. learning_rate_positive       - lr > 0
 11. learning_rule_valid          - rule ∈ {PES, BCM, OJA, STDP}

Population/Architecture (7):
 12. population_neuron_count_positive    - n_neurons > 0
 13. population_dimensions_positive      - dimensions > 0
 14. population_radius_positive          - radius > 0
 15. lateral_inhibition_radius_positive  - radius > 0
 16. homeostatic_target_rate_positive    - rate > 0
 17. neuromodulation_factor_positive     - factor > 0
 18. population_coding_range_positive    - range > 0

Loihi-Specific (3, optional):
 19. loihi_weight_quantizable            - Fits in 8-bit signed int
 20. loihi_ensemble_size_within_limits   - n_neurons ≤ 1024
 21. loihi_delay_in_range                - 0 ≤ delay ≤ 62ms

QUICK IMPLEMENTATION CHECKLIST
================================================================================

For your demo implementation:

□ 1. Import neurocnl
     from neurocnl import run_pipeline, parse, validate, generate, export

□ 2. Write CNL specification
     - Use 4 core concepts minimum (threshold, refractory, decay, weight)
     - Can add extended concepts (delay, STDP, inhibition, population, etc.)
     - Plain English + math (e.g., "exceeds 0.8", "of 0.002 seconds")

□ 3. Test parsing
     for line in spec_text.split('\n'):
         parsed = parse(line)
         assert parsed['concept'] in [13 concepts]

□ 4. Define neuron parameters
     neuron_params = {
         'threshold': 1.0,
         'resting_potential': 0.0,
         'refractory_period': 0.002,
         'tau': 0.02,
         'reset_potential': 0.0,
         'synaptic_weight': 1.5,
     }

□ 5. Validate
     specs = [parse(line) for line in spec_text.split('\n')]
     report = validate(specs, neuron_params)
     assert report['overall'] == True

□ 6. Generate
     net = generate(specs, neuron_params)
     assert net.motor is not None

□ 7. Simulate
     import nengo
     with nengo.Simulator(net) as sim:
         sim.run(1.0)

□ 8. Export
     c_code = export(net, format='c_header')
     with open('network.h', 'w') as f:
         f.write(c_code)

□ 9. Or use one-liner
     result = run_pipeline(spec_text)
     assert result.overall_pass == True

KEY TAKEAWAYS
================================================================================

1. neurocnl translates plain English specs into validated SNNs
   - No machine learning, pure regex parsing
   - Comprehensive validation layer (18 biological invariants)
   - Multi-platform export (C, NeuroML, Loihi, Lava, SpiNNaker)

2. The 13 concepts cover:
   - Core neuron dynamics (threshold, refractory, decay)
   - Synaptic plasticity (STDP, BCM, Oja, learning rates)
   - Network topology (populations, connections, inhibition)
   - Emergent properties (lateral inhibition, homeostasis, neuromodulation)

3. Complete pipeline automation via run_pipeline()
   - Parses, validates, generates, simulates, asserts in one call
   - Returns PipelineResult with full diagnostic info
   - Handles errors gracefully

4. Hardware-ready export
   - C header code for embedded deployment (Teensy, Arduino)
   - NeuroML for neuroscience community
   - Native support for Loihi, Lava, SpiNNaker neuromorphic chips
