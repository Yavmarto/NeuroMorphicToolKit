# Security Policy

## Reporting a Vulnerability

The NeuroBench team takes security seriously. If you discover a security vulnerability in this project, please report it to us as soon as possible.

### Reporting Process

To report a vulnerability, please send an email to [security@example.com](mailto:security@example.com) with the following information:

*   A description of the vulnerability.
*   Steps to reproduce the vulnerability (including any necessary code or scripts).
*   Potential impact of the vulnerability.

Please **do not** report security vulnerabilities through public GitHub issues.

### Disclosure Policy

We follow a responsible disclosure policy:

1.  We will acknowledge receipt of your report within 48 hours.
2.  We will investigate the issue and provide a timeline for a fix.
3.  We will notify you once the vulnerability has been addressed.
4.  We ask that you do not disclose the vulnerability publicly until we have had a reasonable amount of time to fix it.

### Scope

This security policy applies to the NeuroBench repository, including the backend, frontend, and benchmark modules.
