| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The Neuro-space team takes the security of our software seriously. If you believe you have found a security vulnerability in NeuroChip, please report it to us as soon as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

### Reporting Process

1.  **Email:** Send a detailed report to [security@neuro-space.local](mailto:security@neuro-space.local).
2.  **Information to Include:**
    *   A description of the vulnerability.
    *   Steps to reproduce the issue.
    *   Potential impact of the vulnerability.
    *   Any suggested mitigations.
3.  **Acknowledgement:** You will receive an acknowledgement of your report within 48 hours.
4.  **Investigation:** We will investigate the report and may contact you for further information.
5.  **Disclosure:** Once a fix is developed, we will coordinate a public disclosure.

We appreciate your help in keeping NeuroChip secure.
