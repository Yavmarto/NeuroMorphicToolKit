# 03: Analysis and Validation

Once a network is authored, CNLStudio provides a suite of tools to analyze its structure, validate its correctness, and explore parameter distributions.

## The Pipeline Lifecycle

When you edit code in the CNL Editor or change the Canvas, the application runs a background pipeline:
1. **Parse:** Converts the CNL text into an Abstract Syntax Tree (AST).
2. **Validate:** Checks for topological and logical errors (e.g., connecting to a non-existent population).
3. **Generate:** Compiles the network into the Neural Intermediate Representation (NIR).

You can track this progress in the **Pipeline Bar** at the bottom of the screen.

## Validation Panel

The **Validation Panel** is the primary diagnostic tool for your network.
- **Visual:** A tab/drawer usually located on the right side of the Studio screen.
- **Content:** It lists all warnings and errors generated by the backend compiler.
- **Interactivity:** Clicking on an error often highlights the offending line in the CNL Editor.
- **Agent Note:** If a network fails to simulate or deploy, agents must *always* check the Validation Panel or the `validationProvider` state to diagnose the compiler error.

## Parse Results Table

The **Parse Results Table** gives a tabular overview of your network's recognized components.
- **Content:** It lists all parsed Entities (Populations, Inputs) and Relationships (Projections).
- **Usage:** Use this to verify that the compiler actually understood your CNL text as intended. If you define 5 populations but only 4 show up in the table, there is a syntax issue.

## Network Graph View

The **Network Graph View** (`network_graph_view.dart`) provides a static, read-only topological map of your compiled network.
- Unlike the interactive Canvas editor, this view shows the *final compiled structure* of the NIR graph.
- It is useful for verifying how high-level CNL abstractions were expanded into lower-level graph nodes.

## Parameter Explorer

The **Parameter Explorer** allows you to inspect the mathematical properties of your network.
- **Content:** It displays weight distributions, bias histograms, and individual neuron parameters.
- **Usage:** Before deploying to hardware, use the Explorer to ensure that your weights haven't exploded and are within safe ranges for quantization.

## Workspace Comparison Panel

When iterating on designs, the **Workspace Comparison Panel** is invaluable.
- **Content:** It provides a `diff` view between your current workspace and a previously saved workspace.
- **Usage:** If a network suddenly stops performing well, you can load a working workspace into the comparison panel to see exactly which parameters or connections were changed.
