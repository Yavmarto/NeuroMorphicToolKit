# Test Integration Plan: Intel Lava

## Overview
This document outlines the testing integration plan for the **Intel Lava framework (`lava-nc`)** within the NeuroMorphicToolKit (NMTK). The integration relies on translating NeuroCNL SNN graphs into Lava's `LIF` and `Dense` processes to run on Loihi 2 hardware or CPU/GPU simulators.

## Usable Tutorials & Examples to Test

### 1. Neuro-Dream-Hand Loihi 2 Deployment Testing
There is a readily available, executable script in the `Neuro-Dream-Hand` submodule designed expressly for testing Lava / Loihi hardware deployment mappings.

**Script Path**: `Neuro-Dream-Hand/scripts/step13_loihi_deployment.py`

**What it tests**:
- Compiles the trained Nengo SNN parameters into the Lava framework.
- Instantiates the `LoihiExporter` which internally utilizes the `hw_mode` flags to target either the physical Loihi 2 hardware or the software emulator.
- Compares measured hardware latency and energy against an estimated CPU baseline.

**How to run (Simulation/Emulator)**:
To validate that the pipeline can generate valid `Loihi2SimCfg` code without physical hardware:
```bash
python Neuro-Dream-Hand/scripts/step13_loihi_deployment.py --weights output/sleep_weights.npz --target simulated
```

**How to run (Physical Hardware)**:
If you have an Intel Loihi 2 board connected, you can deploy to the actual hardware via the `Loihi2HwCfg` path:
```bash
python Neuro-Dream-Hand/scripts/step13_loihi_deployment.py --weights output/sleep_weights.npz --target loihi2
```

**Expected Outcome**:
A successful run will generate an analytics report saved to `output/step13_loihi_deployment.json` showcasing metrics such as step latency (ms), energy estimate (pJ), and total spikes.

### 2. NeuroCNL Lava I/O Exporter Stubs
To test the core exporter functionality isolated from the robotic hand application:
- You can leverage `neurocnl/neurocnl/export/lava_exporter.py`
- Run its built-in automated test suite to ensure the translator correctly formats node parameters (`shape`, `du`, `vth`, `weights`) into the respective Python execution strings for Lava:
```bash
pytest neurocnl/neurocnl/export/test_exporters.py -k "lava"
```

## Official Documentation and External Tutorials

If you want to validate your implementations against the official behaviors or build larger Lava processes manually outside NMTK to test equivalence, consult the official Intel Lava framework resources:

- **Official Website:** [lava-nc.org](https://lava-nc.org/)
- **GitHub Repository & Tutorials:** The `tutorials/` directory at [github.com/lava-nc/lava](https://github.com/lava-nc/lava) contains excellent Jupyter notebooks covering `Process` creation, `ProcessModel` mapping, and End-to-End SNN workflows. These serve as the ground truth for checking if the code generated by NMTK's exporter aligns with official Lava standards.
