## Core Principles & Guardrails

### Design Consistency (P1b Update)
- **Converge onto Shad:** Converge onto Shad-backed design-system primitives. Remove ad-hoc Material/custom wrappers where possible.
- **Hybrid Bridge Rule:** Keep custom wrappers (like `NmtkSurfaceCard`) only where they bridge shell mode, status semantics, or module-specific contracts that Shad primitives do not natively express.

### Safe Operations (Dirty Files)
- **Safety Default:** Skip dirty files (uncommitted changes) unless the task explicitly owns them. 
- **Preservation:** If a dirty file is the intended write set, explicitly name it and preserve existing edits/context. Faster models must not normalize context they don't understand.

## Task Resolution Detail

### P0: Destructive template load in neurocnl
- Status: **Resolved**
- Resolution: Implemented `isDirty` check in `TemplateGallery` using `workspaceProvider`. Added inline confirmation banner.

### P1: Neurosense color contrast (Light Mode)
- Status: **Resolved**
- Resolution: Migrated hardcoded `Colors.red` and `Colors.green` to `NmtkShellTokens.errorColor` and `NmtkShellTokens.healthyColor`.

### P1b: UI Library Convergence & Layout Hardening
- Status: **Resolved**
- Resolution: Converged onto Shad-backed primitives. Replaced legacy Material buttons with `ShadButton`. Refactored `NmtkSurfaceCard` and acquisition widgets to use stable `Container` structures with Shad decoration tokens, resolving all `RenderBox` and `LayoutBuilder` runtime assertions.

### P2a — "Ownership Boundary" card repeated verbatim on 3 screens
- Status: **Resolved**
- Resolution: Removed from `HardwareScreen` and Neurochip surfaces; centralized in `AnalysisScreen`.

### P2b — Neurochip AnalysisScreen has zero design system usage
- Status: **Resolved**
- Resolution: Refactored using `NmtkSurfaceCard`, `NmtkShellTokens`, and `ShadButton`.

### P3 — 24 `IconButton` instances without tooltip (systematic a11y gap)
- Status: **Resolved**
- Resolution: Global pass, add `tooltip: '...'` to every `IconButton`.

### P4: em-dash usage (Neurochip/neurocnl)
- Status: **Resolved**
- Resolution: Global find-and-replace of `—` with `-` or `:` in UI strings and localizations.

### P4: Shadow/Elevation Discipline
- Status: **Resolved**
- Resolution: Removed `BoxShadow` from `studio_screen.dart` and canvas widgets. Set `elevation: 0` on Material popups in `cnl_editor.dart`.

### H7: Expert Affordances (Global Search/Shortcuts)
- Status: **Resolved**
- Resolution: Implemented `NmtkShortcutScope` in `main.dart` providing global `Cmd+K` and `Cmd+B`. Built `NmtkCommandPalette` with fuzzy search and keyboard-driven action execution. Centralized all suite-wide intents and module navigation in `NmtkCommandProvider`. Updated tooltips to include shortcut hints.
