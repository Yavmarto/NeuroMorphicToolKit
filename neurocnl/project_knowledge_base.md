# Project Knowledge Base

## 1. Framework APIs

### Nengo & NengoLoihi
- **Creating Ensembles:** In Nengo, populations of neurons are created using `nengo.Ensemble(n_neurons, dimensions, neuron_type=...)`. The `dimensions` parameter specifies the dimensionality of the represented value.
- **Connecting Ensembles:** Connections between neural populations (synaptic weights) or from sensory input to populations are made using `nengo.Connection(pre, post, transform=...)`, where `transform` defines the synaptic weight matrix.
- **LIF Neuron Parameters:**
  - Nengo provides the `nengo.LIF` neuron model.
  - **`tau` (Membrane time constant):** Defined via `tau_rc` (default is typically 0.02s). Controls the exponential decay of the membrane potential.
  - **`refractory_period`:** Defined via `tau_ref` (default is typically 0.002s). The time during which the neuron cannot spike after emitting a spike.
  - **`reset_potential`:** In standard Nengo `nengo.LIF`, this is analogous to `min_voltage` (default is 0). It is the voltage the membrane returns to after a spike.
  - **`threshold`:** In Nengo's normalized model, the firing threshold is fixed at $1.0$, while the biological threshold variations are managed through the neuron's `gain` and `bias` (or `intercepts`). When explicitly setting biological constraints, we map the conceptual threshold to the input current required to reach this normalized value of 1.

### MuJoCo (InvertedPendulum-v4)
- **Control Interface:** MuJoCo environments simulate physical control tasks. `InvertedPendulum-v4` consists of a cart that moves linearly, balancing a pole.
- **Input (Action) Shape:** A 1D array of shape `(1,)` representing the continuous force applied to the cart. It is typically bounded (e.g., `[-3.0, 3.0]`).
- **Output (Observation/State) Shape:** A 4D array of shape `(4,)` representing:
  1. Cart position
  2. Pole angle
  3. Cart velocity
  4. Pole angular velocity

### NeuroML (Physical Invariants for LIF Neurons)
- **Membrane Potential Decay (`tau`):** The membrane potential ($V$) decays exponentially towards the resting potential over time with a time constant $\tau$. Mathematical invariant: $\tau > 0$.
- **Threshold:** The voltage level at which an action potential (spike) is generated. Mathematical invariant: Threshold must be strictly greater than the resting membrane potential.
- **Reset Potential:** The voltage value the membrane potential is instantly set to immediately following a spike. Mathematical invariant: Reset potential must be less than or equal to the threshold.
- **Refractory Period:** The strictly positive duration immediately following a spike during which the neuron's membrane potential is fixed at the reset potential and ignores incoming synaptic input. Mathematical invariant: Refractory period $> 0$.
- **Depolarization Rule:** Membrane potential must not decrease during active depolarization (excitatory input).

## 2. Project Constraints Summary

### Out of Scope
- Creating our own neuroscience ontology (we must use NeuroML).
- Building a custom hardware compiler (we must use Lava / NengoLoihi).
- Developing a general-purpose Software Design Document (SDD) platform.
- Providing support for multiple neuron models in version 1 (restricted to LIF).
- Supporting a freeform natural language interface (the CNL must remain strictly constrained, not open-ended).

### The 3-Layer Architecture
- **Layer 1 (Physical Invariants):** The foundational layer consisting of non-negotiable biological and physical laws (derived from NeuroML). Serves as a hard validation backstop that all generated specs must satisfy.
- **Layer 2 (Behavioral Spec):** The human-readable source of truth written in a Controlled Natural Language (CNL). It is unambiguous but accessible to domain experts (e.g., neuroscientists). This defines the system's behavior.
- **Layer 3 (Validation Assertions):** Auto-generated by an LLM based on Layer 2 and ratified by humans. It forms a formal test suite (pytest-style) that verifies the system. Code is only compiled for hardware once Layer 3 assertions pass against Layer 1 constraints.
