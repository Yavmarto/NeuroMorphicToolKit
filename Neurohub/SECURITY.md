# Security Policy

## Supported Versions

The following versions of NeuroHub are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of NeuroHub seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

### How to report

Please do **not** open a public GitHub issue for security vulnerabilities. Instead, send an email to **security@neuro-space.example.org** (placeholder) with the following information:

- A descriptive title for the vulnerability.
- A detailed description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including any sample code or configuration).
- Your name and how you would like to be credited.

### Our Process

Upon receiving a report, we will:

1.  Acknowledge receipt of your report within 48 hours.
2.  Investigate the issue and confirm the vulnerability.
3.  Work on a fix and determine a release schedule.
4.  Notify you once the fix has been released.
5.  Publicly disclose the vulnerability (if appropriate) with credit to you for the discovery.

Thank you for helping keep NeuroHub secure!
