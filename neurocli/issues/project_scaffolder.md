# CLI Project Scaffolder

**Source:** Brobots Neuromorphic analysis spec (04_accessibility_tools.md)

## Objective
The Brobots spec proposes a "Project Scaffolder" CLI to generate project skeletons. This new module `neurocli` will handle the terminal side of bootstrapping neuromorphic projects.

## Tasks
- [ ] Initialize the `neurocli` Python package structure.
- [ ] Build a CLI command interface, e.g., `neuro new --framework lava --target loihi2 --task kws`.
- [ ] Include bundled defaults/templates for major frameworks and tasks.
- [ ] Output a standard boilerplate project directory with `requirements.txt` and annotated scripts.
